# 성경 장별 미디어 콘텐츠 통합 제작 지침

## 1. 목적

성경 각 장을 하나의 **Scene Pack**으로 구조화하고, 동일한 장면을 기반으로 다음 콘텐츠를 통합 제작함.

* YouTube Shorts
* Bible Quiz
* 노래 가사(Lyrics)
* 이미지 및 영상용 Visual Prompt

핵심 원칙은 다음과 같음.

> **성경 한 장 → 하나의 중심 메시지 → 여러 Scene → 하나의 Scene Pack**

Shorts, Quiz, Lyrics, 이미지를 각각 따로 기획하지 않고 **동일한 성경 본문과 Scene을 공유하도록 제작함.**

---

# 2. 전체 제작 구조

```text
성경 한 장
    ↓
본문 구조 분석
    ↓
장의 중심 메시지 결정
    ↓
5~7개 Scene으로 분할
    ↓
각 Scene의 본문·메시지 결정
    ↓
Scene별 Image Prompt
    ↓
Scene별 Shorts
    ↓
Scene별 Quiz
    ↓
Scene별 Lyrics 역할 배정
    ↓
전체 Lyrics 완성
    ↓
본문·신학·콘텐츠 일치 검토
```

기본 Scene 수는 **6개**로 함.

단, 본문의 구조에 따라 5~7개 범위에서 조정 가능함.

---

# 3. 가장 중요한 원칙 — Scene First

콘텐츠를 먼저 만들고 이미지를 맞추지 않음.

먼저 성경 본문을 의미 있는 **Scene 단위**로 나눈 후 모든 콘텐츠를 해당 Scene에서 파생시킴.

```text
Scene
├── Bible
├── Message
├── Image Prompt
├── Shorts
├── Quiz
└── Lyrics
```

따라서 하나의 Scene은 단순한 영상 장면이 아니라 **성경 본문을 미디어 콘텐츠로 전환하는 기본 단위**임.

---

# 4. 본문 분석

먼저 해당 장 전체를 읽고 구조를 파악함.

다음 사항을 확인함.

* 사건의 흐름
* 예수님의 말씀
* 하나님의 명령
* 약속
* 경고
* 반복되는 표현
* 중요한 인물
* 신학적으로 중요한 전환점
* 장 전체의 결론

BibleHub의 Chapter Summary 등을 참고할 수 있으나, 최종적인 기준은 **성경 본문**으로 함.

---

# 5. 장의 중심 메시지

Scene을 나누기 전에 반드시 해당 장을 관통하는 **하나의 중심 메시지**를 먼저 결정함.

중심 메시지는 가능하면 한 문장으로 작성함.

예: 마태복음 5장

> **하나님 나라의 백성은 마음에서부터 변화되어 세상의 소금과 빛으로 살아감.**

각 Scene은 독립적인 주제를 가질 수 있지만 최종적으로 이 중심 메시지를 향해야 함.

---

# 6. Scene 분할

한 장을 기본적으로 **6 Scene**으로 분할함.

Scene은 단순히 절 수를 균등하게 나누지 않고 **본문의 의미 단위**를 기준으로 분리함.

예: 마태복음 5장

| Scene | 본문     | 핵심 내용               |
| ----- | ------ | ------------------- |
| 01    | 1–12절  | 팔복                  |
| 02    | 13–16절 | 소금과 빛               |
| 03    | 17–20절 | 율법의 완성              |
| 04    | 21–37절 | 행동을 넘어 마음까지 보시는 하나님 |
| 05    | 38–47절 | 보복 대신 사랑, 원수 사랑     |
| 06    | 48절    | 하나님 아버지를 닮아가는 삶     |

Scene 수를 맞추기 위해 성경의 자연스러운 문맥을 억지로 분리하거나 합치지 않음.

---

# 7. Scene별 기본 정보

각 Scene에는 최소한 다음 정보를 기록함.

```text
Scene 번호:
본문:
Scene 제목:
핵심 내용:
핵심 메시지:
대표 구절:
Shorts:
Quiz:
Lyrics 연결:
Image Prompt:
```

예:

```text
Scene 05

본문:
마태복음 5:38–47

제목:
원수를 사랑하라

핵심 내용:
보복하지 말고 원수를 사랑하며 박해하는 사람을 위해 기도하라고 하심.

핵심 메시지:
하나님 나라의 사랑은 나를 사랑하는 사람에게만 머물지 않음.

대표 구절:
“너희 원수를 사랑하며 너희를 박해하는 자를 위하여 기도하라.”

Shorts:
원수 사랑 설명 부분

Quiz:
예수님께서는 원수를 어떻게 대하라고 하셨을까요?

Lyrics:
Bridge

Image:
상처를 준 사람을 위해 조용히 기도하는 청년
```

---

# 8. Image Prompt 제작

각 Scene마다 **하나의 마스터 이미지 Prompt**를 작성함.

이미지는 Shorts와 Lyrics 영상에서 공동 사용함.

## 기본 Visual Style

전체 성경 콘텐츠가 하나의 시리즈처럼 보이도록 기본 스타일을 통일함.

* 밝고 청량한 청춘 감성
* 현대의 20대 한국인 남녀
* 자연스럽고 편안한 표정
* 현대적인 일상과 자연
* 맑은 하늘
* 따뜻한 자연광
* 흰색·연청·베이지·파스텔 계열 의상
* 희망적이고 서정적인 분위기
* 현대적인 CCM 뮤직비디오 감성
* 자연스럽고 영화적인 사진
* 과도한 종교적 상징 지양

신앙적인 의미는 가능하면 다음 요소를 활용하여 은유적으로 표현함.

* 빛
* 하늘
* 길
* 바람
* 자연
* 관계
* 표정
* 손을 내미는 행동
* 함께 걷는 모습

---

# 9. 인물 일관성

가능하면 한 장의 Scene Pack에서는 **동일한 주요 인물이 반복 등장**하도록 함.

예:

```text
Scene 01
말씀을 듣고 하늘을 바라보는 청년

Scene 03
자신의 마음을 돌아보는 같은 청년

Scene 04
친구와 화해하는 같은 청년

Scene 05
상처 준 사람을 위해 기도하는 같은 청년

Scene 06
친구들과 세상으로 걸어가는 같은 청년
```

이를 통해 이미지 모음이 아니라 **하나의 짧은 이야기**처럼 보이게 함.

---

# 10. 이미지 화면 비율

마스터 이미지는 기본적으로 **16:9 가로형**으로 제작함.

Shorts에서는 중앙 부분을 **9:16으로 Crop**하여 재사용함.

따라서 Prompt 작성 시:

* 주요 인물을 중앙에 배치
* 중요한 행동을 중앙 영역에서 표현
* 화면 가장자리에 핵심 요소 배치 금지
* 중앙 9:16 영역에서도 의미가 유지되도록 구성
* 적절한 주변 여백 확보

이미지 안에는 원칙적으로 **글자를 생성하지 않음.**

성경 구절, 제목, 자막, 가사는 영상 편집 과정에서 별도로 추가함.

---

# 11. Shorts 제작

Shorts는 약 **1분 이내**를 기본으로 함.

별도의 이야기를 새롭게 만들지 않고 Scene 순서대로 해당 장의 흐름을 전달함.

기본 구조:

```text
Hook
↓
Scene 01
↓
Scene 02
↓
Scene 03
↓
Scene 04
↓
Scene 05
↓
Scene 06
↓
Final Message
```

각 Scene 설명은 짧고 명확하게 작성함.

Shorts의 목적은 해당 장의 모든 내용을 설명하는 것이 아니라,

> **1분 안에 장 전체의 흐름과 중심 메시지를 이해하게 하는 것**

임.

---

# 12. Shorts와 이미지 연결

Shorts 대본에는 필요할 경우 Scene 번호를 표시하여 영상 제작 시 바로 연결할 수 있도록 함.

예:

```text
[Scene 01]
예수님은 세상이 생각하는 복과 다른 복을 말씀하십니다.

[Scene 02]
그리고 제자들을 세상의 소금과 빛이라고 부르십니다.

[Scene 03]
예수님은 율법을 없애신 것이 아니라 완성하러 오셨습니다.

[Scene 04]
하나님은 행동만이 아니라 마음까지 보십니다.

[Scene 05]
그래서 보복을 넘어 원수까지 사랑하라고 말씀하십니다.

[Scene 06]
하나님 나라의 백성은 하늘 아버지를 닮아가는 사람입니다.
```

---

# 13. Quiz 제작

Quiz도 동일한 Scene을 기반으로 제작함.

기본적으로 **Scene당 핵심 문제 1개**를 만듦.

6 Scene이면 기본 6문제가 됨.

Quiz는 단순 암기보다 **해당 Scene의 핵심 내용을 기억하도록 돕는 문제**를 우선함.

---

# 14. Quiz 기본 형식

기본적으로 다음 구조를 사용함.

```text
질문
선택지
정답
간단한 설명
관련 Scene
관련 본문
```

예:

```text
Scene 05

Q. 예수님께서는 원수를 어떻게 대하라고 말씀하셨을까요?

① 피하라
② 똑같이 갚으라
③ 사랑하고 기도하라
④ 아무 관계도 맺지 말라

정답: ③

설명:
예수님은 원수를 사랑하며 박해하는 사람을 위해 기도하라고 말씀하셨습니다.

본문:
마태복음 5:44
```

Quiz의 정답과 설명은 반드시 본문에서 확인 가능해야 함.

---

# 15. Lyrics 제작

기본 원칙은 **성경 한 장 = 대표곡 한 곡**임.

한 장의 모든 내용을 억지로 가사에 넣지 않음.

각 Scene을 노래 구조와 연결하여 장 전체의 흐름을 하나의 노래로 만듦.

기본 연결:

```text
Scene 01 → Verse 1
Scene 02 → Chorus
Scene 03 → Pre-Chorus 또는 Verse
Scene 04 → Verse 2
Scene 05 → Bridge
Scene 06 → Final Chorus / Outro
```

본문에 따라 자유롭게 조정 가능함.

---

# 16. Lyrics는 Scene에 종속시키지 않기

Lyrics와 Scene을 연결하지만 가사를 Scene별 설명문처럼 만들지 않음.

Scene은 **가사의 성경적·내용적 근거**로 사용함.

노래 전체의 음악적 흐름과 운율이 더 중요함.

예:

Scene 05의 핵심이 원수 사랑이라면,

설명형:

> 예수님은 원수를 사랑하고 박해하는 사람을 위해 기도하라고 말씀하셨네

보다

서정적 가사:

> 사랑할 수 없는 그 사람까지
> 기도할 수 있는 마음 주소서

처럼 표현함.

---

# 17. Lyrics 기본 구조

```text
Verse 1
Pre-Chorus
Chorus

Verse 2
Pre-Chorus
Chorus

Bridge

Final Chorus
Outro
```

본문의 특성에 따라 일부 구조를 생략하거나 변경할 수 있음.

---

# 18. Chorus 우선 원칙

노래를 작성할 때 가능하면 **Chorus를 먼저 설계**함.

Chorus는 해당 장의 중심 메시지를 가장 명확하고 기억하기 쉽게 표현해야 함.

예: 마태복음 5장

```text
우리는 세상의 소금이라
우리는 세상의 빛이라
어둔 세상 작은 빛 되어
아버지의 영광 비추리
```

Chorus만 들어도 해당 장의 중심 메시지를 어느 정도 이해할 수 있어야 함.

---

# 19. Lyrics 운율

가사는 읽기 좋은 문장보다 **부르기 좋은 문장**을 우선함.

* 한 줄에 하나의 의미
* 지나치게 긴 문장 지양
* 한 연의 문장 길이를 비슷하게 유지
* 자연스러운 반복 활용
* 어려운 신학 용어 최소화
* 문장 끝의 어감과 리듬을 가능한 한 통일

예:

```text
바라보리
걸어가리
노래하리
비추리
```

음절 수를 기계적으로 동일하게 맞추지는 않되 실제 노래했을 때 호흡 차이가 지나치게 크지 않도록 함.

---

# 20. Lyrics의 서정성

다음과 같은 이미지를 활용할 수 있음.

* 빛
* 새벽
* 아침
* 하늘
* 바람
* 길
* 들판
* 눈물
* 강물
* 씨앗
* 나무
* 노을

그러나 본문과 무관한 아름다운 표현을 넣기 위해 성경 메시지를 약화시키지 않음.

> **서정성은 말씀을 아름답게 전달하는 수단이지 목적이 아님.**

---

# 21. 성경 직접 인용

성경의 핵심 문장을 가사에 직접 사용할 수 있음.

예:

```text
너희 원수를 사랑하며
너희를 박해하는 자를 위하여 기도하라
```

가사 안에는 원칙적으로 다음과 같은 출처를 붙이지 않음.

```text
(마태복음 5:44)
```

단, 제작 데이터에는 해당 가사가 어떤 본문을 기반으로 했는지 Scene의 `Bible` 정보로 기록함.

---

# 22. 개혁주의 신학 기준

Shorts, Quiz, Lyrics 모두 다음을 기준으로 검토함.

* 성경
* 존 칼빈 『기독교 강요』
* 하이델베르크 요리문답
* 웨스트민스터 신앙고백
* 웨스트민스터 소요리문답

특히 Lyrics에서는 다음을 주의함.

### 행위구원 표현 금지

```text
내가 선하게 살아
하늘나라 얻으리
```

와 같은 표현을 사용하지 않음.

기본 흐름은:

> **은혜 → 믿음 → 변화 → 순종 → 감사 → 하나님께 영광**

으로 함.

### 인간 중심 메시지 지양

막연한 자기긍정이나 자기성취보다

* 하나님
* 그리스도
* 은혜
* 믿음
* 회개
* 순종
* 성화
* 하나님께 영광

을 중심으로 함.

---

# 23. Scene 간 Story Flow

Scene들은 각각 독립된 이미지가 아니라 하나의 이야기로 연결되어야 함.

가능하면 다음과 같은 변화가 나타나도록 함.

```text
말씀을 들음
    ↓
자신의 마음을 돌아봄
    ↓
하나님의 은혜를 깨달음
    ↓
관계가 변화됨
    ↓
사랑과 순종을 실천함
    ↓
세상 속으로 나아감
```

모든 성경 장에 이 구조를 기계적으로 적용하지 않고 본문의 실제 흐름을 우선함.

---

# 24. Scene Pack 표준 형식

최종적으로 각 장을 다음과 같은 구조로 정리함.

```text

```

# 25. 마태복음 5장 예시

# 27. 최종 검토 Checklist

## 본문

* [ ] Scene 구분이 실제 성경 문맥과 일치하는가?
* [ ] 장 전체의 중요한 흐름이 빠지지 않았는가?
* [ ] 중심 메시지가 해당 장을 제대로 대표하는가?

## Visual

* [ ] 각 Scene 이미지가 본문의 의미를 표현하는가?
* [ ] 동일 인물과 스타일이 유지되는가?
* [ ] Shorts와 Lyrics 양쪽에서 사용할 수 있는가?
* [ ] 16:9와 9:16 Crop 모두 가능한가?
* [ ] 불필요한 종교적 클리셰가 과도하지 않은가?

## Shorts

* [ ] 약 1분 안에 전달 가능한가?
* [ ] Scene 순서와 본문의 흐름이 일치하는가?
* [ ] 설명이 지나치게 길지 않은가?
* [ ] 마지막에 장의 중심 메시지가 분명한가?

## Quiz

* [ ] 각 문제의 정답을 본문에서 확인할 수 있는가?
* [ ] 단순한 말장난이나 함정 문제가 아닌가?
* [ ] Scene의 핵심 내용을 기억하도록 돕는가?
* [ ] 정답 설명이 짧고 명확한가?

## Lyrics

* [ ] 해당 장의 중심 메시지가 분명한가?
* [ ] Chorus가 장 전체를 대표하는가?
* [ ] 설명문이 아니라 실제 노래의 언어인가?
* [ ] 운율과 문장 길이가 자연스러운가?
* [ ] Scene과 연결되면서도 하나의 노래로 자연스러운가?
* [ ] 행위구원이나 인간 중심 표현이 없는가?
* [ ] 마지막이 하나님과 그리스도를 향하는가?

# 28. 최종 제작 원칙

> **본문을 먼저 이해하고,
> 본문을 Scene으로 나누며,
> Scene에서 모든 미디어 콘텐츠를 파생시킨다.**

따라서 제작 순서는

> **Image → Shorts → Quiz → Lyrics**

가 아니라,

> **Bible → Message → Scene → Visual → Shorts · Quiz · Lyrics**

임.

Shorts는 **말씀을 짧게 이해하게 하고**,
Quiz는 **말씀을 기억하게 하며**,
Lyrics는 **말씀을 마음으로 고백하게 하고**,
Visual은 **그 모든 콘텐츠를 하나의 이야기로 연결함.**

## 한 문장 원칙

> **성경 한 장을 하나의 메시지로 이해하고, 하나의 Scene Pack으로 구성하여, 보고 듣고 기억하고 노래할 수 있는 하나의 콘텐츠 세트로 만든다.**
